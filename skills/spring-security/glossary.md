# Glossário Spring Security

- **Authentication**: prova de identidade.
- **Authorization**: decisão de acesso.
- **Principal**: entidade autenticada.
- **Authority/Role**: permissão atribuída ao principal.
- **SecurityFilterChain**: cadeia de filtros de segurança Servlet.
- **CSRF**: ataque de requisição forjada cross-site.
- **OAuth2 Client**: app que obtém/usa tokens para chamar recursos.
- **Resource Server**: API que valida bearer tokens.
- **OIDC**: camada de identidade sobre OAuth2.
- **SAML2**: protocolo XML comum em SSO enterprise.
- **PasswordEncoder**: componente para hash/verificação de senha.
- **Method Security**: autorização em métodos.

# NoSQL, Mapping e Auditing

## MongoDB

Spring Data MongoDB combina template API, repositories, object mapping, queries, aggregation, change streams, transactions/sessions e observability.

## Mapping

Preserve o modelo do datastore. Documento não é entidade JPA; chave-valor não é tabela relacional.

## Auditing e Projections

Use auditing para rastrear criação/modificação e projections para reduzir acoplamento e carga de dados.

# Commons, Repositories e Queries

## Commons

Spring Data Commons fornece conceitos compartilhados:

- repositories;
- query methods;
- projections;
- auditing;
- custom conversions;
- entity callbacks;
- Kotlin support;
- AOT.

## Repositories

Use interfaces para declarar intenção de acesso. Escolha a interface base conforme necessidade.

## Query Methods

Derivação por nome funciona bem para consultas simples. Quando o nome cresce demais, use query explícita ou custom implementation.

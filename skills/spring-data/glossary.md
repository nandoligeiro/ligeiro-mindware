# Glossário Spring Data

- **Repository**: abstração de acesso a dados.
- **CrudRepository**: operações CRUD básicas.
- **PagingAndSortingRepository**: paginação e ordenação.
- **Query Method**: método cujo nome deriva uma query.
- **Projection**: visão parcial/interface/DTO de dados.
- **Auditing**: preenchimento automático de created/modified metadata.
- **Custom Repository**: implementação customizada acoplada ao repository.
- **Entity Callback**: callback em lifecycle de entidade.
- **Specification**: composição de predicates para JPA.
- **R2DBC**: acesso relacional reativo.
- **Spring Data Commons**: base compartilhada dos módulos Spring Data.
